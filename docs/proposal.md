# Moon Scrub 项目申报书（非正式参考稿）

## 一、项目名称和仓库

- 项目名称：Moon Scrub——面向日志、API 与 AI 工作流的敏感信息脱敏引擎
- 计划仓库：https://github.com/yyqdbngt/moon-scrub
- MoonBit 模块：`yyqdbngt/moon_scrub`
- MoonCakes 版本：`yyqdbngt/moon_scrub@0.1.0`（已独立安装验证）
- 许可证：Apache-2.0

## 二、项目简介

开发者经常需要把日志发给排障平台、把 API 数据导出给测试环境，或把错误信息和代码片段
交给 AI 助手分析。这些文本中可能混入访问令牌、Bearer 凭据、JWT、密码、邮箱、IP 地址
和支付卡号。人工检查不稳定，直接记录正则命中的原值又会制造第二次泄露。

Moon Scrub 是一个纯 MoonBit、离线、确定性的敏感信息检测与脱敏组件。它在字符串进入
日志系统、第三方 API 或 AI 服务之前进行扫描，返回不含秘密原值的类别与位置报告，并按
指定策略生成脱敏文本。项目不依赖网络和外部服务，适合在 wasm、wasm-gc、js 和 native
应用中作为轻量安全边界使用。

## 三、项目方向与应用场景

项目方向为开发者安全工具和数据治理基础组件，覆盖以下通用场景：

1. **日志与可观测性：** 在应用日志进入文件、控制台或集中采集系统前移除密码、令牌、
   邮箱和 IP，批量统计只保留类别数量。
2. **AI 提示词保护：** 开发者粘贴报错、配置或接口响应给 AI 之前，本地清理访问令牌、
   Bearer 凭据、JWT 和个人标识；扫描过程不联网。
3. **API 与数据导出：** 对测试数据、客服记录和调试响应执行统一脱敏，可选择完全标记、
   类型标记或在允许时保留末四位。
4. **CI 与开发工具集成：** 对生成日志或示例输出二次执行 `verify_clean`；如果仍有启用
   规则可识别的内容，调用方可以中止上传或发布。

## 四、核心功能

- 识别常见访问令牌前缀、Bearer token、JWT 和敏感键值赋值。
- 识别私钥块和带用户名/密码的 URL，并支持调用方传入精确秘密规则。
- 识别邮箱、合法 IPv4，以及通过 Luhn 校验的支付卡号候选。
- 提供 `secrets_only` 与 `standard` 两种扫描策略。
- 提供 Marker、Typed、PreserveLast4 三种脱敏样式。
- 对重叠命中排序与去重，保持替换偏移稳定。
- `Finding` 不保存命中原值，只返回类型、置信度和 UTF-16 区间。
- 批量处理保持每一行，输出安全分类统计和脱敏结果。
- 结构化字段按 path 和内容双重判断；password、token 等敏感路径采用整体脱敏。
- 已脱敏文本可以再次处理，支持二次验证。

## 五、实际场景测试

`examples/log-pipeline` 模拟四条应用日志：一条同时包含邮箱和内网 IP，一条包含 Bearer
凭据，一条包含 Luhn 有效的示范卡号，一条为普通性能日志。程序输出脱敏后的四行文本，
摘要为 changed-lines 3、findings 4；普通日志保持不变，报告中不保存任何命中原值。

测试还生成 10,000 行确定性混合日志，其中邮箱、密码、IPv4 和普通文本各 2,500 行。
验收结果为输出仍有 10,000 行、改变 7,500 行、发现 7,500 项，三个启用类别各 2,500
项。其他测试覆盖重叠匹配、引号赋值、非法 IPv4、未通过 Luhn 的号码、策略开关、三种
脱敏样式、幂等性、二次扫描、结构化字段、私钥块、URL 凭据和自定义规则。

## 六、技术路线与验收边界

项目使用 MoonBit 实现 ASCII 结构识别、候选区间生成、Luhn 校验、区间排序合并、策略
过滤、字符串重建及批量统计。当前约 840 行核心 MoonBit、200 行测试、18 个测试块，
示例和文档不计入统计。CI 在 wasm、wasm-gc、js、native 四后端执行格式、
静态检查、构建、测试和示例。

当前验收边界是结构明确的秘密与常见标识符，不做自然语言人名、地址识别，不读取文件或
环境变量，不上传输入，不管理密钥，也不声称提供完整 DLP 或法规合规。检测可能误报或
漏报；调用方仍需按风险设置拒绝策略。`PreserveLast4` 会保留部分字符，高敏感场景应使用
完全标记。

## 七、原创性与生态价值

项目为独立的纯 MoonBit 实现。选题调研未发现 MoonBit 生态中定位相同、同时提供秘密
检测、PII 候选识别、安全 Finding、重叠合并、批量统计与多后端验证的通用包。它填补的
不是某一种业务格式，而是所有日志、接口、AI 和数据工具都会遇到的输出安全问题。
